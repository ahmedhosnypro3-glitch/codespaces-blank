CHAIN SEMANTICS (how a PASS is bound to the current bytes)
  OK         = judged render attested to the CURRENT deliverable md5 (render_meta /
              render_check / REJUDGE_REPORT / equivalent evidence near the render).
  STALE      = other md5s attested near the judged render (current md5 not among them).
  UNVERIFIED = no md5 attestation found near the judged render.
  NO-RENDER  = the judged render file no longer exists.
  A transcript counts only if its body carries a terminal FINAL VERDICT: PASS/FAIL line.
  Precedence: chain-verified PASS > chain-verified FAIL on current bytes > any PASS
  (=> CERTIFIED-UNVERIFIED) > any FAIL > NO-VERDICT. UNVERIFIED is a legitimate state;
  no verdict is ever invented.
