## Notable audit findings (slides 018–034)

- **slide 023** was the only file in the deck with **zero URLs** — it named only
  generic textbooks with no citable links. Four real flowchart sources were added;
  this was a lane-S rule violation and is now fixed.
- **slide 018**: the certified `slide_018_final.json` prints `∂E/∂w_ij`, while the
  frame label, the parse transcript, and slides 19–22 all read `w_ji` — an index
  inversion to fix at build time (same issue recorded on slide 19).
- **slides 027/028/031**: the live-fetched Matt Mazur canonical example is a
  *different* network (inputs 0.05/0.10, 2 hidden nodes, η = 0.5, targets
  0.01/0.99). It confirms the frame's computational order and formulas, **not** the
  deck's specific numbers. One grounded-search response returned model-fabricated
  arithmetic (a 2-hidden-node variant, net_h1 = 1.2); it was discarded, not cited.
- **slides 030/031**: the course uses the ALREADY-UPDATED output-layer weights
  inside the hidden-layer `Σ_k(δ_k w_kj)` sums. The canonical worked example
  explicitly uses the ORIGINAL weights. Recorded as a course convention — the frame
  wins for recreation. Also `ΔW32=5*0.005*1=0.125` is arithmetically impossible
  (it needs the multiplier 5).
- **slide 031**: the certified JSON prints `W42=0.075+0.075=0.15`, but its own ΔW
  line and slide 30's parse transcript give `W42=0.5+0.075=0.575`.
- **slide 032**: all TEN values of the "after iteration # 1" panel match the run's
  computed new-weight set exactly (the prior note claimed nine).
- **slides 029/031**: transcribed noise in the analysis JSON (`−0.344`/`−0.445` vs
  the correct `−0.134`/`−0.455`) — a build that carries both draws a wrong diagram.
- **slide 034**: the "Squared Error" column is `Σₖ(tₖ−Oₖ)²` **without** the ½
  factor — all six rows verified to <1e-5. Any regenerated error plot must use the
  same rule.
- **η = 5** on slides 27–34 is reproducible and internally consistent on every
  line, but is far outside the usual 0.01–0.1 range (Mazur's own example uses
  0.5). Reproduce verbatim; do not "correct" it.
