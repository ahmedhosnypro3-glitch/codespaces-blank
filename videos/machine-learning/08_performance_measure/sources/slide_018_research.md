- Per-class metrics are computed One-vs-Rest: the chosen class is positive, all other classes collapse into the negative group: CONFIRMED — scikit-learn, "sklearn.metrics.classification_report" (https://scikit-learn.org/stable/modules/generated/sklearn.metrics.classification_report.html) — For any class i, precision/recall/F1 are computed from the binary view with class i positive; this is the convention the slide's three separate "Positive Class" panels assume.
- Precision of a class = TP divided by the COLUMN total (all samples predicted as that class): CONFIRMED — Lightly AI, "Confusion Matrix" (https://www.lightly.ai/blog/confusion-matrix) and TrainInData, "Confusion matrix precision and recall" (https://blog.trainindata.com/confusion-matrix-precision-and-recall/) — Precision_k = C[k,k]/sum(column k) = TP/(TP+FP); the FP term is the sum of the off-diagonal column entries from the other classes.
- Recall of a class = TP divided by the ROW total (all samples truly of that class): CONFIRMED — TrainInData, "Confusion matrix precision and recall" (https://blog.trainindata.com/confusion-matrix-precision-and-recall/) and Math StackExchange, OvR verification (https://math.stackexchange.com/questions/5110423/verifying-one-vs-all-precision-and-recall-calculations-from-a-multi-class-confusion) — Recall_k = C[k,k]/sum(row k) = TP/(TP+FN); the FN term is the off-diagonal row entries.
- DOG: Precision = 5/(5+4+7) = 5/16 and Recall = 5/(5+2+1) = 5/8: CONFIRMED — locally re-computed from the slide's own matrix against the OvR rules above — Dog column total = 5+4+7 = 16, Dog row total = 5+2+1 = 8, so 0.3125 and 0.6250 exactly as printed.
