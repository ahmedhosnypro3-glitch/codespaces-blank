- "Activation Function: Sigmoid function (0, +1)" — the sigmoid's output range is (0, 1): CONFIRMED — DataCamp, "Sigmoid Function" (https://www.datacamp.com/tutorial/sigmoid-function) — sigma(x) = 1/(1+e^-x) squashes any real input strictly between 0 and 1, so the "(0, +1)" range on the slide is the sigmoid's defining property.
- 'Threshold at "0.5"': CONFIRMED — DataCamp, "Sigmoid Function" (https://www.datacamp.com/tutorial/sigmoid-function) and scikit-learn, "Tuning the decision threshold for binary classification" (https://scikit-learn.org/stable/modules/classification_threshold.html) — A sigmoid score >= 0.5 predicts the positive class, < 0.5 the negative; 0.5 is the default baseline and also where sigma(0) = 0.5.
- Shift from slide 019's bipolar {-1, +1} step at threshold 0 to this slide's sigmoid (0, 1) at threshold 0.5: CONFIRMED — DataCamp, "Sigmoid Function" (https://www.datacamp.com/tutorial/sigmoid-function) — Both are binary-threshold conventions; the sigmoid differs by squashing to (0,1) and being smooth/differentiable (usable with gradient descent, unlike the non-differentiable step).
- Sigmoid output is interpretable as a probability for the positive class: CONFIRMED — DataCamp, "Sigmoid Function" (https://www.datacamp.com/tutorial/sigmoid-function) — Bounded (0,1) outputs are naturally read as class probabilities; this is why the 0.5 cutoff is standard.
- Model maps "[Any value] -> [0, +1]" then thresholds to a predicted class, with labels (+1, 0): CONFIRMED — scikit-learn, "Tuning the decision threshold for binary classification" (https://scikit-learn.org/stable/modules/classification_threshold.html) — predict_proba-style scores in [0,1] with a 0.5 cutoff produce the hard label; the 0.5 default can be tuned per metric.
- Label encoding shown as (+1, 0) matching the sigmoid's (0, 1) output range: CONFIRMED — scikit-learn, "Tuning the decision threshold for binary classification" (https://scikit-learn.org/stable/modules/classification_threshold.html) — With a (0,1) output the natural target encoding is {0, 1} (or {1, 0} as the slide orders it for the positive class); no conflict between labels and output range.
