- Formula "Precision = TP / TP + FP": CONFIRMED — "sklearn.metrics.precision_score documentation" (https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_score.html) — same TP/(TP+FP) definition; cross-referenced from slide 007 (no new query spent).
- Worked example "Precision= 5/(5+0)" then "= 100%": CONFIRMED — "sklearn zero-division semantics for precision" (https://www.stackoverflow.com/questions/62326735/metrics-f1-warning-zero-division) with the base definition at (https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_score.html) — with FP = 0 and TP > 0, precision = TP/(TP+0) = 1.0, i.e. perfect 100% precision; sklearn treats the undefined case (TP=0 and FP=0) separately via zero_division, which does not apply here.
- Definition fraction "Correctly Classified (as Positive) / Total Classified as Positive (either Correct and Erroneous)": CONFIRMED — "Han & Kamber Ch.8 precision definition" (https://www.slideshare.net/slideshow/08-classbasic/39057275) — numerator TP, denominator TP+FP; identical to slides 007-008 (banked record reused, no new query spent).
- Meaning "% of what you Predicted as POSITIVE is Actually Positive": CONFIRMED — "Google ML Crash Course — precision" (https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall) — banked record reused, no new query spent.
- Callout pairing "Positive Classified as +ive" / "Negative Classified as +ive" bracketed as "All Samples classified as Positive": CONFIRMED — Han/Kamber Ch.8 matrix (https://www.slideshare.net/slideshow/08-classbasic/39057275) — TP + FP is the full predicted-positive column, the precision denominator.
- Blue note "Whatever objects you retrieved as positive, I can trust you (Irrespective of how many MISSED Positive samples)": CONFIRMED — "Evidently AI — precision vs recall" (https://www.evidentlyai.com/classification-metrics/accuracy-precision-recall) — precision ignores false negatives entirely, so it is independent of how many positives were missed; that is what recall measures.
