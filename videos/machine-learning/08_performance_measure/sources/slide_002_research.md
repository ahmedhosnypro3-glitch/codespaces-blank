# Sources — Slide 2 — Training Samples with Labels [0,1] (Two Classes)

Spec: analysis/slide_002_final.json.

- Sigmoid activation maps any real input to the range (0, +1): CONFIRMED — "A Gentle Introduction to the Sigmoid Function", https://machinelearningmastery.com/a-gentle-introduction-to-sigmoid-function/ — σ(z) = 1/(1+e^-z) → 1 as z→+∞, → 0 as z→-∞, σ(0) = 0.5; matches the Activation Function box's "Sigmoid function (0 , +1)".
- Threshold at "0.5" is the standard sigmoid decision cutoff: CONFIRMED — logistic-regression tutorial (FIT NEU), https://fit.neu.edu.vn/en/post/logistic-regression-binary-classification-sigmoid-python-practice — σ(z) ≥ 0.5 predicts class 1, σ(z) < 0.5 predicts class 0; threshold 0.5 is the default, tunable per cost asymmetry.
- Positive-class labels [+1], negative-class labels [0] (the {+1, 0} / [0,1] two-class coding): CONFIRMED — sklearn accuracy_score docs, https://scikit-learn.org/stable/modules/generated/sklearn.metrics.accuracy_score.html — sklearn estimators echo the label convention they were trained on (e.g. LogisticRegression predicts 0/1); {0,1} coding with +1/0 class tags is a valid textbook coding of the two classes.
- Model box caption "[Any value] -> (-1, +1)": CORRECTED — a sigmoid model outputs (0, +1), not (-1, +1) — "A Gentle Introduction to the Sigmoid Function", https://machinelearningmastery.com/a-gentle-introduction-to-sigmoid-function/ — the same slide's Activation Function box states "Sigmoid function (0 , +1)", so (-1, +1) contradicts the slide's own activation description. The spec flagged this as uncertain; per source-research doctrine the slide wins for recreation (keep both strings verbatim) but the source wins for understanding: a sigmoid-based model cannot emit -1.
- Label column headers "Label" repeated per class: CONFIRMED — standard supervised-learning terminology — Han & Kamber ch. 6, https://www3.cs.stonybrook.edu/~cse521/ch6book.pdf — class labels are the ground-truth targets the LOSS node consumes in the Training flow.
- Training flow "Input Sample → Model → Predicted Class → LOSS → Label of Input Sample (+1, 0)": CONFIRMED — logistic-regression tutorial (FIT NEU), https://fit.neu.edu.vn/en/post/logistic-regression-binary-classification-sigmoid-python-practice — a sigmoid classifier emits a probability thresholded to a discrete label, which is then compared against the ground-truth label by a loss term; this is exactly the flow shown.
