## Reinforcement (parallel web-research lane, agy web search)

- One threshold = one confusion matrix = one point in ROC space: CONFIRMED — Wikipedia, "Receiver operating characteristic" (https://en.wikipedia.org/wiki/Receiver_operating_characteristic) — "Each prediction result or one instance of a confusion matrix represents one point in the ROC space"; sklearn `roc_curve` docs (https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_curve.html) — for each threshold the cutoff is applied (predict positive if score >= threshold), a temporary confusion matrix is built, and the parallel (fpr, tpr, thresholds) arrays carry exactly one operating point per index.
- TPR/FPR formulas and ROC axes: CONFIRMED — Evidently AI, "Explain the ROC curve" (https://www.evidentlyai.com/classification-metrics/explain-roc-curve) — TPR = TP/(TP+FN) on the y-axis, FPR = FP/(FP+TN) on the x-axis, each computed at every threshold; sweeping the threshold yields a unique (FPR, TPR) pair per point, which is what the frame's per-threshold panels feed.
- A mid-sweep threshold such as 0.4 sits between 0.3 and 0.5 of the same fixed-model sweep: CONFIRMED — sklearn `roc_curve` docs — the thresholds array is the decreasing unique score cut-offs, so each plotted label (0.0/0.1/0.3/0.4/...) is one array row of the same curve the block is building toward slide 27.
