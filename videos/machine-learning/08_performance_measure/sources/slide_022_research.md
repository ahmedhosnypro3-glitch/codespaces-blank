## Reinforcement (parallel web-research lane, agy web search)

- The threshold partitions the score axis into predicted-positive / predicted-negative at the chosen cut, and one fixed threshold yields one definitive 2x2 matrix: CONFIRMED — Wikipedia, "Confusion matrix" (https://en.wikipedia.org/wiki/Confusion_matrix) — score >= threshold is predicted positive, score < threshold predicted negative; changing the threshold shifts the partition and the matrix cells.
- Raising the threshold (0.1 to 0.3) increases precision and decreases recall: CONFIRMED — Google ML Crash Course, "Classification: Accuracy, Precision, and Recall" (https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall) — threshold up means fewer false positives (precision up) but more missed positives (recall down), and the inverse for threshold down; scikit-learn, "Tuning the decision threshold for class prediction" (https://scikit-learn.org/stable/modules/classification_threshold.html) — the same tradeoff applied to predict_proba scores.
- The matrix cells exhaustively partition the test set (TP+FP+FN+TN = N; actual P = TP+FN; actual N = FP+TN): CONFIRMED — Wikipedia, "Confusion matrix" (https://en.wikipedia.org/wiki/Confusion_matrix) and sklearn `confusion_matrix` API docs (https://scikit-learn.org/stable/modules/generated/sklearn.metrics.confusion_matrix.html) — rows are actual classes, columns predicted classes, C[i,j] counts actual-i/predicted-j (ravel order TN, FP, FN, TP). This is the arithmetic behind the 11-sample constraint used to cross-check this slide's cells.
