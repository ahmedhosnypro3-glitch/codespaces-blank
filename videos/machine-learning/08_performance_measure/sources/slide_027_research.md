- "ROC Curve" is the plot of TPR against FPR at each threshold setting: CONFIRMED — "Receiver operating characteristic", Wikipedia (fetched live) https://en.wikipedia.org/wiki/Receiver_operating_characteristic — verbatim: "The ROC curve is the plot of the true positive rate (TPR) against the false positive rate (FPR) at each threshold setting"; Google ML Crash Course (fetched live) https://developers.google.com/machine-learning/crash-course/classification/roc-and-auc — compute TPR and FPR at each possible threshold, then plot TPR against FPR.
- "Can we combine All thresholds and corresponding Confusion Matrices in one Graph? Solution: Use ROC Curve": CONFIRMED — Wikipedia (fetched live): "Each prediction result or instance of a confusion matrix represents one point in the ROC space"; Google ML Crash Course (fetched live): the ROC curve "shows model performance across all thresholds" — one confusion matrix per threshold, all operating points joined into one curve.
- Name origin — WWII radar operators / electrical engineers: CONFIRMED — Wikipedia (fetched live) verbatim: "The ROC curve was first developed by electrical engineers and radar engineers during World War II for detecting enemy objects in battlefields, starting in 1941, which led to its name ('receiver operating characteristic')" and "Following the attack on Pearl Harbor in 1941, the United States military began new research to increase the prediction of correctly detected Japanese aircraft from their radar signals ... they measured the ability of a radar receiver operator"; Google ML Crash Course (fetched live): "The name ... comes from WWII radar detection".
- "Same Model / Same Test Samples / Performance Measures (TP, TN, FP, FN) are affected by selected threshold / There is a Confusion Matrix for each threshold": CONFIRMED — scikit-learn "Tuning the decision threshold for class prediction" (fetched live) https://scikit-learn.org/stable/modules/classification_threshold.html — tuned-threshold classifiers "provide the same predict_proba outputs and thus the same Receiver Operating Characteristic (ROC) and Precision-Recall curves, the class label predictions differ because of the tuned decision threshold".
- Diagonal (0,0)-(1,1) = random-guess / line of no-discrimination, AUC = 0.5: CONFIRMED — Google ML Crash Course (fetched live) verbatim: "if a model's performance is exactly like random guessing or flipping a coin, its ROC curve is the diagonal from (0,0) to (1,1). AUC is 0.5"; Wikipedia (fetched live): "A random guess would give a point along a diagonal line (the so-called line of no-discrimination) from the bottom left to the top right corners".
- Corner meaning — (0,0) = predict nothing positive, (1,1) = predict everything positive, best point (0,1): CONFIRMED — Google ML Crash Course (fetched live): a perfect model has TPR 1.0 and FPR 0.0, represented by the point (0, 1); Wikipedia (fetched live): "The best possible prediction method would yield a point in the upper left corner or coordinate (0,1) of the ROC space, representing 100% sensitivity (no false negatives) and 100% specificity (no false positives)".
