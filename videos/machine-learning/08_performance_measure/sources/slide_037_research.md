# Sources — Slide 37 — Area Under the Curve (AUC)

- "Best model is the model that has the largest area under the curve": CONFIRMED — ROC and AUC (Google ML Crash Course, https://developers.google.com/machine-learning/crash-course/classification/roc-and-auc) + "What is AUC-ROC?" (Roboflow, https://roboflow.com/blog/what-is-auc-roc) — a larger AUC means higher TPR at low FPR across all thresholds, so the model with the larger area is the better overall classifier.
- "Best Model is the model trying to reach the point at [FBR=0, TPR=1]": CONFIRMED — Receiver operating characteristic, Wikipedia (https://en.wikipedia.org/wiki/Receiver_operating_characteristic) — the top-left corner (FPR = 0, TPR = 1) is the perfect-classifier operating point; a richer curve hugging that corner yields the largest area. The frame's "FBR=0" is a course typo for FPR=0 — recreate the text verbatim, do not silently correct it.
- "Compare between different models (at different thresholds for each model)": CONFIRMED — ROC and AUC (Google ML Crash Course) — ROC/AUC evaluates a model across every decision threshold, which is what makes AUC usable as a single aggregate score for comparing models before committing to one operating point.
- AUC = the probability that a randomly chosen positive instance is scored above a randomly chosen negative instance; 0.5 = random guessing, 1.0 = perfect separation: CONFIRMED — ROC and AUC (Google ML Crash Course) + "Interpretation of the AUC" (DataScience+, https://datascienceplus.com/interpretation-of-the-auc/) + AUC–Mann-Whitney-U chapter (https://slds-lmu.github.io/i2ml/chapters/04_evaluation/04-13-auc-mwu/) — the standard probabilistic definition; AUC equals the normalized Mann-Whitney U statistic, i.e. P(score_positive > score_negative) with ties counting 0.5.
- The random-guess reference line is the diagonal with AUC = 0.5: CONFIRMED — "Explain the ROC curve" (Evidently AI, https://www.evidentlyai.com/classification-metrics/explain-roc-curve) — the y = x diagonal is a model with no discrimination capacity and its area is exactly 0.5; any useful curve lies above it. This matches the frame's straight lines radiating from the origin toward the top-right.

## Second-opinion (lane C, 2026-10-31, agy web search)

- AUC trapezoidal meaning — NEW confirming source: sklearn `metrics.auc` docs (https://scikit-learn.org/stable/modules/generated/sklearn.metrics.auc.html) — `auc(x, y)` computes the area via the composite trapezoidal rule, Area = sum (y_i + y_{i+1})/2 * |x_{i+1} − x_i|, equivalent to numpy.trapz; applied as `auc(fpr, tpr)` from `roc_curve` it yields exactly the ROC-AUC. This pins the "area under the curve" on the frame to the standard trapezoidal computation.
- AUC probabilistic meaning re-CONFIRMED with NEW source: Wikipedia ROC article (https://en.wikipedia.org/wiki/Receiver_operating_characteristic) — AUC equals the probability that the classifier ranks a randomly chosen positive instance higher than a randomly chosen negative instance, and is equivalent to the Mann–Whitney U statistic (ties count 0.5); AUC is bounded in [0,1] inside the unit square, 0.5 = diagonal/random, 1.0 = perfect. Google ML Crash Course roc-and-auc re-CONFIRMED: larger AUC = better model, threshold-invariant aggregate across all thresholds. No corrections.
